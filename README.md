# Compras de gado | Monte do Pasto

Página para preparar os dois emails de cada compra de animais: o email de acordo e o email de valores, com o quadro de cálculo.

## Publicar no GitHub Pages

1. No repositório, carrega o ficheiro `index.html` para a raiz (Add file → Upload files → Commit changes).
2. Vai a **Settings → Pages**.
3. Em **Source**, escolhe **Deploy from a branch**, branch `main`, pasta `/ (root)`, e carrega em **Save**.
4. Passado um ou dois minutos, o endereço aparece no topo dessa página (algo como `https://<utilizador>.github.io/<repositório>/`).

**Não carregues** o ficheiro `definicoes-monte-do-pasto.json` para o repositório. Tem os emails da equipa, e um site do GitHub Pages é público.

## Primeira utilização em cada computador

1. Abre o endereço da página no Chrome ou no Edge.
2. Vai a **Definições → Importar ficheiro** e escolhe `definicoes-monte-do-pasto.json`. Ficam os destinatários, os dados de faturação e as condições habituais.
3. Confirma que o **Outlook** é a aplicação de email predefinida no Windows (Definições → Aplicações → Aplicações predefinidas → procurar "mailto").

## Onde ficam os dados

Os negócios ficam guardados no navegador de cada computador. Para passar negócios de um PC para outro, ou guardar uma cópia, usa **Definições → Exportar ficheiro** num PC e **Importar ficheiro** no outro.

## Atualizar

Para mudar a página, substitui o `index.html` no repositório. O GitHub Pages atualiza sozinho em poucos minutos. Os dados guardados nos navegadores mantêm-se.
